# Yana Shimko — portfolio

Статический сайт-портфолио. Публикуется через GitHub Pages из ветки `main`, папки `/`.

## Файлы

- `index.html` — главная страница и оболочка дроверов.
- `styles.css` — оформление, адаптивность и анимации.
- `app.js` — навигация, языки, тема и галереи.
- `case-data.js`, `igaming-case.js`, `settlers-case.js` — содержимое кейсов.
- `assets/` — изображения, шрифты и резюме.

## Обновление

После проверки правок сохраните их коммитом и отправьте в `main`. GitHub Pages обновит сайт автоматически.

```sh
git add .
git commit -m "Update portfolio"
git push
```

Для локального просмотра запустите статический HTTP-сервер в этой папке.

Материалы портфолио принадлежат их авторам. Публикация репозитория не предоставляет разрешение на повторное использование изображений и работ.
